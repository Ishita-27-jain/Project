** Hospital Patient Readmission Prediction using Machine Learning**
Project Overview

Hospital readmissions are a major healthcare challenge, contributing to increased treatment costs, resource burden, and poorer patient outcomes. This project aims to develop a machine learning model capable of predicting patient readmission risk using structured clinical and demographic healthcare data.

The goal was to support data-driven clinical decision making by identifying patients at high risk of readmission and enabling early intervention strategies.

Objectives
Analyze hospital patient datasets for readmission-related trends
Preprocess healthcare records for machine learning readiness
Address missing values and class imbalance
Build predictive classification models
Compare algorithm performance for optimal prediction accuracy
Interpret features contributing most to readmission risk
Methodology
Data Preprocessing
Cleaned patient demographic and clinical records
Removed duplicate/inconsistent entries
Imputed missing values
Encoded categorical medical features
Scaled numerical variables
Managed imbalanced classes using resampling techniques (SMOTE if used)
Exploratory Data Analysis

Analyzed:

Age distribution
Admission type trends
Diagnosis frequency
Medication and treatment correlations
Historical readmission patterns
Machine Learning Models

Implemented predictive classifiers such as:

Logistic Regression
Random Forest
Decision Tree
XGBoost
Support Vector Machine
Model Evaluation

Evaluation metrics:

Accuracy
Precision
Recall
F1-score
ROC-AUC
Confusion Matrix

Feature importance analysis performed to identify major predictors influencing hospital readmission.

Tech Stack

Programming: Python
Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
Domain: Healthcare Analytics, Predictive Modeling, Machine Learning

Key Outcomes
Developed a predictive healthcare risk assessment model
Improved understanding of readmission-associated clinical factors
Demonstrated application of machine learning in healthcare operations and patient outcome optimization
